UPDATE 2026-07-16: 70x70 mm RESCALE — muscle_wire_driver_70x70.kicad_pcb
------------------------------------------------------------------------
The strip design below was reworked onto a 70 x 70 mm board (4 limb
channels, same schematic/netlist — original strip file left untouched).

- Outline (10,10)-(80,80); 4x M2.5 NPTH mounting holes at corners.
- Floor plan: J1 left edge center | support cluster + U1 | two channel
  rows: ch1 | U2 | ch2 (y=30) and ch3 | U3 | ch4 (y=60), opamp BETWEEN
  its two channels per the plan below — feedback-part congestion gone.
  J2 right edge center; drains fan to it at 0.6 mm.
- Fully routed: all 37 nets, 553 segments, 135 vias (incl. ~70 GND
  stitching vias on a 7 mm grid). +10V at 0.8 mm, VCC/GND 0.4 mm,
  drains 0.6 mm, signals 0.25 mm. SET/ADC runs mostly B.Cu; F.Cu keeps
  power + local channel wiring. C4/C5 at U2/U3 VCC pins, C3 at VREF pin 8.
- GND: explicit tracks connect every GND pad (verified without zone
  credit) + full-board GND zones on both layers, UNFILLED in file.
- Verified programmatically: every net one connected component; all
  inter-net copper clearances >= 0.2 mm (JLC 2 oz rules).
- Preview: board_70x70_preview.png (red F.Cu / blue B.Cu / grey vias).

ORIGINAL STRIP (71 x 8.6 mm) NOTES BELOW
==================================================================

WHAT IS DONE AND VERIFIED
- Board outline 71 x 8.6 mm (fits 10 mm ID tube: sqrt(8.6^2 + 3.7^2) = 9.4 mm
  diagonal at the connector, less elsewhere).
- All 53 footprints placed (genuine KiCad library footprints), every pad
  assigned to the correct net from the schematic. Placement follows the strip
  floor plan: J1 (SH-6, cable exits left) | support | AD5593R | MCP6002 |
  ch1 | ch2 | MCP6002 | ch3 | ch4 | J2 (SH-4, exits right).
- GND zones on both layers (thermal relief, island control), design rules
  set for JLCPCB 2 oz: 0.2 clearance / 0.25 track / 0.6-0.3 via.
- Scaffold routing that survived DRC pruning: +10V lane (y=8.15) with diode
  cathode stubs, VCC lane/trunk, part of the B.Cu signal bus, GND stitching.
- J1/J2 mounting-tab pads trimmed/pulled inboard 0.35 mm to fit the 8.6 mm
  width (housing tabs still land mostly on pad — note for assembly review).

WHAT REMAINS
- ~35 local connections (FB/OUT/GATE/SNS per channel, SDA/SCL/A0/RESET/VREF/
  LED at the left end) plus re-adding pruned bus segments.
- KNOWN ISSUE: the channel blocks are packed too tightly for the feedback
  parts (R_i1/C_i1) — several pad-to-pad clearances < 0.2 mm around the
  opamps. Track routing cannot fix these; parts must move.

RECOMMENDED COMPLETION PATH (interactive, ~1-2 h in KiCad)
1. Stretch the board to ~76-79 mm (length is free inside the straw) and
   re-space: give each channel block ~9 mm pitch, or better, place each
   MCP6002 BETWEEN its two channels (rot 0: pins 1-3 face west to the odd
   channel, pins 5-7 east to the even channel) — this removes all feedback-
   part congestion.
   Alternative that keeps 71 mm: put R_i1/C_i1 on the BACK side under each
   opamp (stack becomes 0.8+1.75+0.55 = 3.1 mm; diagonal 9.14 mm still fits).
   JLC does 2-sided assembly, or hand-solder 8 rear 0603s.
2. Route with these embedded conventions (already partly in the file):
   - B.Cu bus corridor y 0.7-3.5: SET1-4 on y 0.7/1.1/1.5/1.9 (deepest lane
     gets the westmost riser at U1 so risers never cross lanes);
     ADC1-4 on y 3.5/3.1/2.7/2.3 (shallowest lane to the westmost channel,
     same non-crossing rule; riser order at U1 east side: ADC4,3,2,1).
   - DRAIN1-4 on B.Cu y 6.8-8.0 (or 5.35-6.55 if fb parts stay front),
     0.4 mm width, via down at x = BX+2.74 per channel, fan to J2 at the
     right end with nested staggered verticals.
   - +10V stays the F.Cu lane at y 8.15; VCC lane y 0.45 + vertical trunk
     through the U2 body gap; GND entirely by pours + stitching vias
     (stitch only at y~4.3 between blocks — never inside the bus corridor).
   - Keep DAC (SETx) traces on the far side of the board from the drain
     switching; VREF cap C3 ties directly to U1 pin 8.
3. Refill zones, run DRC, fix stragglers, then:
   - File > Fabrication Outputs > Gerbers + drill (JLC 2-layer, 2 oz, 0.8 mm)
   - Fabrication Toolkit plugin > one-click JLC BOM + CPL.

ELECTRICAL NOTES CARRIED INTO LAYOUT
- 2 oz copper, back layer = heat spreader: flood drain pads, generous pour.
- Sense resistor grounds: short, direct to pour with adjacent stitching via.
- Worst case 2 x 0.58 W (antagonistic pairs, held mid-current) — spreader
  sized for this; PWM-assist firmware removes it entirely if needed.

UPDATE 2026-07-20: 4-LIMB BOARD — muscle_wire_driver_4limb.kicad_pcb
------------------------------------------------------------------------
70 x 88 mm, 2 layer, 2 oz. FOUR complete limb drivers (16 SMA channels),
Arduino Nano R4 socket, MPU6050 header, single 10V/GND power tether.

- Limb strips L1-L4 (top to bottom), each = AD5593R + 2x MCP6002 +
  4x IRLML6344 + flybacks/sense, JST-SH-4 actuator connector at LEFT edge
  (J101/J201/J301/J401, wires exit left). In-use LED per limb.
- A1 = Arduino Nano R4 socket (2x15 x 2.54mm, USB faces RIGHT edge).
  Used pins: VIN <- +10V, 5V -> VCC rail, GND x2, A4/A5 = shared I2C,
  D2-D5 = SEL1-4 (one per limb), D6 = MPU6050 INT (all RA4M1 digital
  pins support attachInterrupt).
- J1 = 10V/GND screw terminal (right edge): powers muscle wires AND the
  Nano via VIN -> autonomous operation needs only this one tether.
- J2 = 1x5 header for MPU6050 breakout (GND, VCC, SDA, SCL, INT).
- I2C addressing/select: all four AD5593R share one bus. Each A0 is
  pulled low (0x10, idle) via R{i}04; drive its SEL line HIGH -> chip
  moves to 0x11 AND its LED lights. Talk to 0x11 only while exactly one
  SEL is high. R900/R901 = single 4.7k bus pullup pair.
- IMPORTANT - AD5593R I/O pin mapping differs from the single-limb
  schematic (chosen for routability; I/O roles are register-configured):
    I/O0=SET3  I/O1=ADC3  I/O2=SET2  I/O3=SET1
    I/O4=ADC4  I/O5=SET4  I/O6=ADC2  I/O7=ADC1
  => DAC_CONFIG (0x05) = 0x002D, ADC_CONFIG (0x04) = 0x00D2.
  Firmware map per limb: SET[1..4] = I/O 3,2,0,5; ADC[1..4] = I/O 7,6,1,4.
- Verified programmatically: all 133 signal nets single connected
  component (explicit copper), all clearances >= 0.2 mm. GND connects by
  full-board pours both layers (unfilled in file - press B in KiCad)
  plus ~42 stitching vias; decoupling grounds use thermal-relief pour
  connection (normal practice).
- Remaining in KiCad: refill zones, DRC, silkscreen tidy-up, fab outputs.
  Schematic file not regenerated - the PCB netlist is authoritative;
  redraw as hierarchical sheet x4 if schematic needed.
- Power budget: <=2 limbs' antagonistic pairs active => worst ~2.2 A on
  10V input; 0.6-0.8 mm rails at 2 oz OK. Nano 5V regulator load ~40 mA.
